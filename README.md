# StyleHub – Clothing Sales and Ordering System

## Project Overview

StyleHub is a Java-based Clothing Sales and Ordering System developed to help manage clothing products, customer orders, and inventory. The system provides an organized platform for customers to browse and purchase clothing products while allowing administrators to manage the store's operations.

The project aims to make clothing sales and order management more convenient, efficient, and organized.

## Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Database:** MySQL
- **Database Connectivity:** JDBC (MySQL Connector/J)
- **IDE:** NetBeans
- **Database Management:** phpMyAdmin / XAMPP

## Main Features

- Customer Registration and Login
- Customer Product Browsing
- Shopping Cart Management
- Product and Category Management
- Order Placement and Management
- Inventory and Stock Management
- Sales and Order Reports
- Administrator Management

## Database Information

The system uses MySQL as its database management system.

**Database Name:** `stylehub_db`

The database stores information related to users, products, inventory, and customer orders.

## How to Run the Project

1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP file.
3. Open NetBeans IDE.
4. Open the StyleHub project.
5. Start Apache and MySQL using XAMPP.
6. Import the provided `stylehub_db.sql` file into phpMyAdmin.
7. Check the database connection settings in the Java database configuration file.
8. Ensure that MySQL Connector/J is properly added to the project libraries.
9. Run the project through NetBeans.
